What is Command Prompt?

The essentials — what CMD is, how it differs from PowerShell, how to open it, and the handful of ideas that make every command make sense.

What is CMD?

Command Prompt (cmd.exe) is the classic command-line interpreter built into every version of Windows. It lets you talk to Windows directly by typing text commands instead of clicking icons — to manage files and folders, check system and network status, run programs, and automate repetitive tasks with batch scripts.

It's the descendant of MS-DOS's COMMAND.COM, which is why many CMD commands (dir, copy, del) still look and feel like DOS commands from the 1980s — but they run fully inside modern Windows.

How to open CMD

Quick launch: Press Win + R, type cmd, press Enter.

Start Menu: Click Start, type "Command Prompt", press Enter.

Run as Administrator: Right-click the Command Prompt result and choose "Run as administrator" — required for system-level commands like changing network settings or managing services.

From File Explorer: Type cmd in the address bar of any folder to open a prompt already pointed at that folder.

CMD vs PowerShell vs Terminal

Command Prompt (cmd.exe) — the original, lightweight, text-in/text-out shell. Great for quick tasks and legacy batch files.

PowerShell — a much more powerful modern shell built on .NET; works with objects, not just text, and can do almost everything CMD does plus far more (scripting, automation, remote management). Most classic CMD commands still work inside it.

Windows Terminal — not a shell itself, but a modern tabbed app that can host CMD, PowerShell, and WSL/Linux sessions side by side.

How commands are structured

Almost every CMD command follows the same basic shape:

COMMAND [parameters] [/switches or -flags]

For example, in dir /a /s C:\Projects — dir is the command, C:\Projects is the target, and /a and /s are switches that change its behaviour (show hidden files, search subfolders).

  • Switches almost always start with / in CMD (unlike Linux, which uses - or --).
  • CMD is not case-sensitive — DIR, dir, and Dir all work identically.
  • Type any command followed by /? to see its full built-in help, e.g. xcopy /?.
  • Press Tab to auto-complete file and folder names as you type.
  • Press ↑ / ↓ to cycle back through previously typed commands.

The core idea: a "current directory"

CMD is always "standing" inside one folder at a time — shown in the prompt, e.g. C:\Users\Salim>. Commands like dir or copy act on that folder unless you give a full path. cd changes which folder you're standing in.

Paths: absolute vs relative

Absolute: starts from a drive letter, e.g. C:\Users\Salim\Docs. Relative: starts from wherever you currently are, e.g. Docs\report.txt or ..\Backup (.. means "one folder up").

Drives

Each disk/partition gets a letter (C:, D:...). Typing a drive letter with a colon and Enter (e.g. D:) switches CMD to that drive.

A first walkthrough

cd C:\Users\Salim\Documents
Move into the Documents folder.
mkdir SiteReports
Create a new folder called SiteReports.
cd SiteReports
Move into the folder just created.
echo Panel inspection notes > notes.txt
Create a text file containing that line.
dir
List what's in the current folder — you should see notes.txt.
type notes.txt
Print the file's contents to the screen.
