Signal Strength & Quality Parameters

Understand the key cellular metrics used for cell selection, throughput performance, and handover triggers.

RSRP

Power

Reference Signal Received Power. Measures average power of reference signals.

Level: -85 dBm (Good)
> -80 dBm : Excellent
-80 to -90 dBm : Good
-90 to -100 dBm : Fair
< -100 dBm : Poor

RSRQ

Quality

Reference Signal Received Quality. Indicates RF quality considering interference.

Level: -10 dB (Good)
> -10 dB : Excellent
-10 to -15 dB : Good
-15 to -20 dB : Poor

SINR

SNR / Noise

Signal-to-Interference-plus-Noise Ratio. Primary driver for MCS modulation order (QAM).

Ratio: 18 dB (64-QAM)
> 20 dB : 256-QAM (Top Speed)
13 to 20 dB : 64-QAM
0 to 13 dB : 16-QAM / QPSK

Walkie-Talkie vs Cellular

Half-Duplex Operation

Only one radio can transmit on a given frequency at a time. Releasing PTT returns unit to Rx mode.

No Core Infrastructure

Direct peer-to-peer RF links operate independently of towers, cellular core networks, or SIM cards.

Repeater Mode

Elevated repeaters receive on Frequency A and retransmit simultaneously on Frequency B to double range.
