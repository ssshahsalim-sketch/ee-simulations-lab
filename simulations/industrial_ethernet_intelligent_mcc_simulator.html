Stratix Managed Ethernet Switch

IP: 192.168.1.2 | Layer 2 Switching Engine

Ethernet Switch Behavior Principles:
  • Ingress: Switch inspects the Source MAC Address of incoming frames to populate its internal MAC Table.
  • Egress: Switch inspects the Destination MAC Address to lookup the target outbound port.
  • Unknown Unicast / Broadcast: If Destination MAC is unknown or standard broadcast (FF:FF:FF:FF:FF:FF), frame is flooded to all ports except ingress.

Architectural Comparison: Hardwired Discrete I/O vs Ethernet Communication

Traditional Hardwired Architecture

  • Wiring: Requires individual copper conductors for Start (DO), Stop (DO), Fault (DI), Speed Ref (4-20mA AO), Speed Feedback (4-20mA AI).
  • Diagnostics: Limited to binary fault contact status. No detailed motor current, thermal capacity, or fault codes available.
  • Installation Cost: High labor costs for pull wires, termination, labeling, and troubleshooting broken connections.

Intelligent Ethernet Architecture

  • Wiring: Single industrial Ethernet CAT6 / RJ45 cable carries all control commands, speed references, and diagnostic telemetry.
  • Diagnostics: Full access to internal VFD parameters, torque, DC bus voltage, ground fault warnings, overload trip history, and thermal status.
  • Flexibility: Modify control behavior and speed scaling entirely in PLC ladder software without changing physical MCC panel wiring.
