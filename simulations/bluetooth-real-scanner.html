This works in Chrome, Edge, or Opera on desktop or Android. It does not work in Safari, iOS (any browser — Apple blocks Web Bluetooth platform-wide), or Firefox. It also needs a secure context — if you opened this file directly and see this message, try serving it locally (e.g. python3 -m http.server and open via http://localhost:8000) instead of via a bare file:// path.

Exactly what's real here, and what a webpage genuinely cannot get (read first)

Real: the "Scan" button below opens your operating system's actual Bluetooth chooser — the same dialog a native app would trigger — listing real devices your hardware detects nearby. If you pick a device and it supports Bluetooth Low Energy GATT services, this page performs a genuine gatt.connect() and reads real characteristic values: manufacturer name, model number, firmware/hardware/software revision, and battery level, when the device exposes them.

Not possible from any webpage, on any browser:

  • Most earbuds and speakers stream audio over Bluetooth Classic (A2DP), not BLE GATT — browsers have no API for Classic Bluetooth at all, so audio devices will usually show a name but fail to connect for data, exactly like the tool will tell you if that happens.
  • There's no browser API that reports a live "connection speed" or "transfer speed" for a Bluetooth link — that number simply isn't exposed to web pages by any browser, so this tool won't invent one. Where useful, it shows the typical published range for that class of radio, clearly labelled as a reference figure, never a live reading.
  • The device "type" (earbuds / speaker / phone / wearable) shown below is a guess based on the device's advertised name — Bluetooth's actual "class of device" field isn't exposed to browsers either.
