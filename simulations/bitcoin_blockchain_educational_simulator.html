Step 1: Wallet & Keypair Generation

Bitcoin wallets don't store actual Bitcoins—they store cryptographic key pairs! A random 256-bit Private Key is generated first. From this key, elliptic curve cryptography (secp256k1) derives the Public Key, which is then hashed into a Bitcoin Address.

Cryptographic Key Derivation Flow (One-Way Mathematics)

1. Private Key

Random 256-bit number. Used to digitally sign transactions.

2. Public Key

Derived via ECDSA (secp256k1). Impossible to reverse calculate Private Key.

3. Bitcoin Address

Derived via HASH160 (SHA-256 + RIPEMD-160) + Base58Check encoding.
