How this maps to the real build

Step 1 — Software
You are here. Every algorithm below (R-peak detection, HRV math, FFT band power, state classifier) is real code, running on synthetic data. Nothing here is a mockup — it's the exact pipeline your hardware will feed.
Step 2 — Heart Hardware
AD8232 (ECG) or MAX30102 (PPG) + ESP32. This is the easier half — well documented, cheap, achievable in days.
Step 3 — Mind Hardware
NeuroSky TGAM module recommended over building your own EEG analog front-end. Raw DIY EEG is a serious, noisy, multi-week analog design project.

◈ EEG Band Generator

Relaxed / Eyes Closed
Five classic EEG bands (δ θ α β γ) summed with drifting phase + pink noise, weighted by a mental-state preset. This models the general shape of scalp EEG for teaching purposes — not a clinical-grade signal.

Expected Firmware Protocol

Have the ESP32 send one line per sample over USB-serial (115200 baud) or a BLE UART characteristic, in this exact CSV shape — the parser above is already written to expect it:
millis,ecgRaw,eegRaw 125034,2148,612 125042,2201,598 125050,2183,634 ...
ecgRaw — raw ADC counts from AD8232 output pin (or MAX30102 IR value if using PPG)
eegRaw — raw ADC counts from your EEG front-end, or the TGAM's parsed attention/meditation byte if using NeuroSky's own serial protocol
Keep the loop rate steady — 250–500 samples/sec for ECG, 128–512 samples/sec for EEG is typical.
