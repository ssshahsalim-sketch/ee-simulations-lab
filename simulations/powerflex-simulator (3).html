Safe Torque Off — PowerFlex 525

Safe Torque Off Active Both safety channels must be closed before the drive can restart.
Channel A (S1)
Factory jumper (closed)
Channel B (S2)
Factory jumper (closed)

Both channels must be closed (healthy) for the drive to run. Opening either channel removes IGBT gating immediately — the motor coasts to a stop with no ramp, and the drive cannot restart until both channels are closed and STO Reset is pressed.

PLC Simulator — Control the Drive Over the Network

To actually drive the motor from here (just like a PLC would), set P046 [Start Source1] = "5: EtherNet/IP" (or "4: Network Opt") on the Parameters tab, and turn OFF Local mode on the keypad. Then the Run/Stop buttons and reference slider below write the Control Word / Speed Reference tags shown above, exactly like a PLC program would.
