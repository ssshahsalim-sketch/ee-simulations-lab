Backup & restore data

All data is stored locally in this browser (localStorage) — nothing is uploaded anywhere. Export a JSON backup before clearing browser data, switching devices, or moving the file.

How status & the buy list are calculated

  • Groceries: Finished = quantity is 0. Low = quantity is at or below the minimum level you set. Both are added to the buy list automatically, using the restock quantity you set for that item.
  • Appliances: anything marked Needs Maintenance or Damaged is added to the repair list automatically, sorted by priority.
  • Manual items: anything you add directly on the Buy & Repair List tab, for one-off needs not tied to ongoing stock.
