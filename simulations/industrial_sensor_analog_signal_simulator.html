Wire Break Experiment: 0–20 mA vs 4–20 mA

Demonstrating why 4 mA (Live Zero) prevents catastrophic undetected wire cuts.

System A: 0–20 mA (Dead Zero) NORMAL
Transmitter Output: 0.00 mA
PLC Interpretation: 0.0 Bar (0% Level)
Alarm Status: NO ALARM DETECTED

When pressure is 0 bar, output is 0 mA. If the wire snaps, output is also 0 mA. The PLC cannot distinguish between zero pressure and a severed wire!

System B: 4–20 mA (Live Zero) LIVE ZERO OK
Transmitter Output: 4.00 mA
PLC Interpretation: 0.0 Bar (0% Level)
Alarm Status: NORMAL (LIVE ZERO)

4 mA represents 0 Bar. If signal drops below 3.6 mA (e.g. 0 mA), the PLC instantly knows the cable is broken and triggers an alarm!
